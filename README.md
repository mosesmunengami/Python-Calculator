# Python Calculator

A beginner calculator project built using Python to practice programming fundamentals.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

## What I Learned

Through this project I practiced:

- Python functions
- Variables
- User input
- Conditional statements
- Basic problem solving

## How To Run

1. Install Python on your computer.
2. Download this repository.
3. Run:

python calculator.py
